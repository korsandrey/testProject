Программа для записи данных в файл.
Есть 2 типа запуска:
1-через .exe файл (CMakeProject1/out/build/x64-Debug/CMakeProject1) , тогда нужно указать имя файла и уровень сообщения по умолчанию
2-через консоль , тогда имя файла и уровень по умолчанию можно передать параметрами
(имя файла можно писать без расширения)
после этого можно выбрать дальнейшие действия
запись новой строки
смена уровня по умолчанию
выход из программы


Исходный код можно посмотреть в папке CMakeProject1/CMakeProject1
