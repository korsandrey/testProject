Программа для записи данных в файл.
Есть 2 типа запуска:
1-через .exe файл (в папке ConsoleApplication) , тогда в консоли нужно указать название файла и уровень по умолчанию
2-через консоль , тогда название файла и уровень по умолчанию можно передать параметрами
(название файла можно писать без расширения)
после этого можно выбрать дальнейшие действия
запись новой строки
смена уровеня по умолчанию
выход из программы


Исходный код можно полсмотреть открыв файл TestProject.sln
